HOPFIELD NETWORK MEMORY AND CAPACITY ANALYSIS

This repository contains a suite of Python scripts designed to experiment with and evaluate Hopfield Networks. Utilizing the Olivetti Faces dataset, the project systematically explores memory retrieval, network capacity limits, and the phase transition associated with catastrophic forgetting when the network is overloaded. Furthermore, it investigates alternative learning rules and pattern selection methodologies to mitigate memory interference.

PROJECT OVERVIEW

The primary objective of this repository is to quantify and visualize how Hopfield Networks store and recall patterns, particularly as they approach their theoretical capacity limit (approximately 0.14N).

Key areas of investigation include

    Standard Hebbian Learning: Baseline experiments to test asynchronous recall and calculate energy landscapes.

    Memory Overload and Phase Transitions: Identification and visualization of the exact threshold at which the network degrades and loses retrieval capability.

    Least-Similar Pattern Selection: An experimental approach testing whether minimizing the similarity between stored patterns (measured via normalized dot-product) improves recall accuracy by reducing cross-talk interference.

    Storkey Learning Rule: Implementation of the Storkey weight-update algorithm to compare its capacity and interference mitigation against standard Hebbian learning.

    Energy Landscape Projections: Generation of 2D and smoothed 3D visualizations of the 4096-dimensional Hopfield energy landscape to map the attractor basins of stored memories.

REPOSITORY STRUCTURE

In folder source

analysis.py
The baseline analysis script. It fetches the dataset, applies standard Hebbian learning, executes asynchronous recall on corrupted cues (50 percent missing data), and generates 2D/3D energy landscape plots.

hopfieldfaces.py
A streamlined version of the baseline analysis, specifically configured to generate a visual grid demonstrating the memory degradation spectrum across random subjects.

baseline_overload_tests.py
A targeted stress test on a scaled-down 400-neuron network, highlighting the phase transition when memory load exceeds the theoretical capacity limit.

less_similar.py
An experimental script that constructs training sets using faces identified as the least similar to the target face to observe the effects on memory interference.

storkey.py
Implements the Storkey learning rule to observe potential improvements in network capacity and recall accuracy over the standard Hebbian rule.

result_visualization.py
A comparative analysis utility. It reads the CSV outputs generated by analysis.py and less_similar.py to plot head-to-head performance metrics, including Accuracy, Hamming Distance, and Energy Change.

In folder results

comparison_summary.csv
Stores comparison data between the different experiments

hopfield_results.csv
Baseline results for seed 42

least_similar_hopfield_results.csv
Results for the experiment that deliberately choose non-similar faces

storkey_hopfield_results.csv
Results for Storkey experiment

ENVIRONMENT SETUP

The following instructions detail how to set up the project locally using a Python Virtual Environment (venv).

    Prerequisites
    Ensure Python 3.8 or higher is installed on your system.

    Create the Virtual Environment
    Navigate to the root directory of the project in your terminal and execute the following command to create a virtual environment named venv:

macOS and Linux:
python3 -m venv venv

Windows:
python -m venv venv

    Activate the Virtual Environment
    The environment must be activated before installing dependencies or executing scripts.

macOS and Linux:
source venv/bin/activate

Windows:
venv\Scripts\activate

Install Dependencies
Ensure the updated requirements.txt file (provided in the section below) is present in your working directory, then execute:
pip install -r requirements.txt

EXECUTION GUIDE

Once the virtual environment is configured and active, the scripts can be executed sequentially to generate the experimental data and corresponding visualizations.

Step 1. Generate Baseline Data
Command: python source/analysis.py
Expected Output: hopfield_results.csv, energy landscape plots, and baseline recall grids.

Step 2. Generate Experimental Data
Commands:
python source/less_similar.py
python storkey.py
Expected Output: Additional CSV files (least_similar_hopfield_results.csv, storkey_hopfield_results.csv) and corresponding visualizations.

Step 3. Visualize Comparisons
Ensure the generated CSV files are located in the expected directories (update the paths in result_visualization.py if necessary), then execute:
Command: python source/result_visualization.py
Expected Output: Head-to-head performance comparison graphs saved to the local directory.
